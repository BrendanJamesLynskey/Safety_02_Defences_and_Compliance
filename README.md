# Safety 02 — Defences &amp; Compliance: Guardrails, NIST AI RMF, EU AI Act

A visual engineering deck covering the complete defence-in-depth stack for production LLM deployments: input filtering with Llama Guard 3 (Meta), ShieldGemma (Google), and NeMo Guardrails (NVIDIA); output filtering and content classifiers; system-prompt hardening patterns; tool gating and approval flows; NIST AI Risk Management Framework (AI RMF 1.0); EU AI Act risk tiers and obligations; and documentation requirements including model cards, system cards, and responsible scaling policies (RSPs).
